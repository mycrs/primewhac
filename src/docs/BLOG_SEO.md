# QruzeHD Blog SEO Guidelines

This document outlines the SEO implementation and best practices for the QruzeHD Blog System.

## 1. Heading Hierarchy

Strict HTML heading hierarchy is crucial for search engines to understand the structure of the content.

*   **H1 (Heading 1):** Reserved exclusively for the Blog Post Title. There must be exactly ONE `<h1>` tag on the page. In `BlogPostPage.jsx`, this is hardcoded to render the `post.title`.
*   **H2 (Heading 2):** Used for main sections within the blog content. When creating content in the Admin Editor, main sections must use H2 formatting.
*   **H3 (Heading 3):** Used for subsections nested under H2 headings.
